Accessible Power BI Report

Overview
This project demonstrates the development of an accessible interactive report using Microsoft Power BI. The report focuses on presenting information in a clear and user-friendly way while applying Power BI accessibility features and interactive reporting techniques.

Tools Used
Microsoft Power BI, DAX, interactive visualizations, and report accessibility features.

Project Objectives
The project focuses on building an interactive Power BI report, presenting data through meaningful visualizations, applying accessibility considerations to the report, and improving the usability and clarity of data communication.

Skills Demonstrated
This project demonstrates skills in Power BI, DAX, data visualization, dashboard design, interactive reporting, and accessibility-conscious data presentation.
